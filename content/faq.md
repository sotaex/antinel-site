# 常见问题

一句话：十二个最常被问到的问题，每答都能独立引用——单独摘出来也说得通。

## Antinel 监理到底是什么

一个装在你自己电脑上的独立第三方监理，看住 AI 编程工具的每一次工具调用：该拦的当场拦下、该提醒的提醒、每一件都记账。本地运行、运行时不联网、纯 Python 标准库、无驻留进程。

## 它和杀毒软件有什么区别

杀毒看文件里有没有恶意特征，监理看这次调用的动作合不合规。「Agent 读了你的 `.env` 然后正常退出」不是病毒，杀毒不报，监理当场拦下并记账。两者不替代。

## 装了会不会让电脑变慢

单次钩子调用时延约 {{facts.F-004.value.p50_ms}} 毫秒，其中大部分是 Python 解释器启动的开销。没有常驻后台进程，不占内存，不扫全盘。这个数只在 Windows 上测过，Linux 和 macOS 未测。

## 它会不会把我的数据传出去

不会。运行时零网络、纯标准库、无驻留进程。体检、扫描、账本全部在本机跑完，结果不出本机。这是它作为「向业主负责的监理」的前提——一个要向云端汇报的监理，没法向本地业主负责。

## 要花钱吗

不要。代码以 Apache-2.0 开源，`pip install antinel` 就装上了。我们不出售「认证」「推荐位」「通过标识」，也不承接「帮我过检」的活——那会让判据不再中立。详见[许可与中立](/license/)。

## 支持哪些系统和 AI 工具

第一版平台是 Windows。已验证能真实拦截的宿主是 Claude Code、ZCode、Qoder；其余宿主装完是审计与扫描模式，`antinel install` 会明说，不算装失败。登记表里共 {{facts.F-003.value.hosts}} 类宿主——**没被列出来的工具不等于安全**，只等于监理没有它的取证路径。

## 已经被拿走的东西能追回来吗

不能。监理是护栏，不是追溯工具：它管住以后，记下已经发生的。要判断「以前有没有被带走」，跑一次体检看六档裁决——🔴 自认打包过、🟠 自认往外发过、🟡 自认在同步，这三档出现就说明有痕迹。

## 「没查到」和「没发现」差在哪

差很远。⚪「查过，没发现记录」是扫描器走到了、这次没找到证据；⚫「没查到」是扫描器根本没走到，这一项监理没查。把两者合并成一句「安全」就是骗人，所以首屏必须报「没查到 N 个」。

## 它能拦住 Agent 删我的文件吗

能拦住命令层面的删除（`DST-01`，严重级，当场拦下）。但**不解析脚本内容**：把删除写进 `.py` 或 `.sh` 再执行，钩子看到的是「运行一个脚本」，拦不住，只留痕告警。要物理隔离，用容器。

## 我不是程序员，能用吗

能。跑 `antinel ui`，浏览器打开本机页面，点一下「开始检查」，出来一页能看懂、能截图的结果。命令行那套是给愿意看细节的人准备的，不是必须。

## 我怎么验证它没骗我

三件事：`antinel verify` 查审计链有没有被动过；`python -m scripts.run_harness` 复跑全部断言，得到你自己的结论（你的结论可以取代随包的）；`python challenge/tamper.py` 亲眼看它怎么被改坏、怎么报错。判据本身也公开在 `rules/default.json` 里，觉得不对就改。

## 为什么叫「监理」，不叫「哨兵」

哨兵只喊不记。监理要按事先写明的口径判定、当场处置、写进台账、事后可复算。一次报警如果没有记录，第二天没人能证明它发生过。展开说在[为什么叫监理](/steward/)。
