# 免费与付费

一句话：软件不要钱，服务要钱。这一页把哪些不要钱、哪些要钱讲明白，不留糊涂账。

## 一张表看完

| | 个人 | 公司 |
|---|---|---|
| 花钱 | 永久免费 | 第一年不要钱，之后永远五折 |
| 装几台 | 你自己这一台 | 你说了算，几台都行 |
| 能看到的结论 | 全部 | 全部 |
| 谁看 | 你自己看 | 团队、客户、董事会 |
| 记录放哪儿 | 放本机 | 本机，另加一份公司汇总 |
| 用公司名字出纸 | 不行，只能自己看 | 行 |
| 有人帮你 | 社区 | 邮件，24 小时内回 |
| 另外收钱 | 没有 | 部署、培训、接系统 |

**表里第三行最要紧。** 个人用的和公司用的，看到的结论一模一样，一条都不少。

为什么这么分：我们不靠瞒着你挣钱。要是个人版能藏结论，「没查到不等于没问题」这句话就白说了。

你花钱买的不是功能，是两样：多少台机器合成一本账，以及纸上署谁的名。

## 第一批进来的公司

第一批 5 席，满了就关。5 席就是 5 席，不是噱头。

头一年不要钱。之后永远五折，按当时的公开价算。

公开价要是涨了，你的五折不变。

这是谢你来得早，不是搞促销。

## 我们答应的三件事

现在出的是 0.x 版。三件事写在公开文件里，不靠嘴说。

1. **升级不丢账。** 格式不换。旧的记录照样读得出来，照样能查。
2. **不干了先说。** 哪天停服务，提前 12 个月告诉你，再给你一份能带走的离线记录。
3. **免费的不变收费。** 现在不要钱的，不因为升级就要钱。

## 五折的几个框框

- 五折跟着这家公司走，不能转给别的公司。
- 只算第一批登记的那几台机器。后来加的，按当时的公开价。
- 公司被收购、拆开、或者换了老板，折扣还认不认，我们坐下来写清楚。

## 我们不做什么

不卖「认证」，不收「通过费」，不接「帮我过检」，也不卖排名和推荐位。

道理很实在。哪天有人能花钱把结论改好，这本账对谁都没用了，包括出钱的那个人。
